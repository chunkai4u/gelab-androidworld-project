# Live demo and verification guide

The current live demonstration is a working prototype: GELab-Zero-4B-preview runs inference on a Runpod L4, controls an AndroidWorld emulator, and completes `SystemWifiTurnOn`. AndroidWorld's official verifier returns PASS.

Start with [the Traditional Chinese presentation guide](LIVE_DEMO.zh-TW.md). It includes the live script, a five-file code tour, the distinction between the agent's `COMPLETE` claim and the official verifier, and a transparent backup plan. Latest reusable evidence is in [`results/development/live-wifi-pass/`](../results/development/live-wifi-pass/).

This is not yet a completed nine-run benchmark evaluation. Markor and SMS tasks remain outstanding.
